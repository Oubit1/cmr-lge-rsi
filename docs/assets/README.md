# Reviewed documentation media

These UI assets were explicitly provided for the project's public presentation.
The editor recording is an excerpt with the case list removed and the identity
bar covered before re-encoding. Both videos have no audio or source metadata.
No original screen recording, patient list, DICOM/NIfTI file or identity mapping
is included. The recording-tool watermark is preserved.

GIF previews render inline in GitHub. MP4 files offer higher-resolution playback
or download. Exact file sizes and SHA-256 digests are bound by approved-media.json;
replacements must be reviewed again. See ../PUBLIC_RELEASE.md for the review scope.
