# Scope and evidence

Implemented: persistent role handoffs, provider-neutral invocation telemetry,
model continuity capsules, bounded retries, independent approval, isolated
implementation, before/after frozen benchmark comparison, source-hash checked
execution with audited receipts, operator feedback ingestion, and UI controls.

Generic QC code and the configurable execution policy are research mechanisms,
not clinical guarantees. Clinical calibration, benchmark assets and patient
cohorts are intentionally not distributed. This release does not reproduce the
private deployment's historic scores, patient outcomes or aggregate results.

A fresh install defaults to mock providers, observe mode and disabled automatic
execution. To establish an autonomous RSI claim on your own data, configure an
independent benchmark and measure non-regressing improvements over successive
approved tool revisions and new cases. A promoted revision, service heartbeat,
token spend or passing unit suite alone is insufficient evidence.

Human edits become structured local feedback. Model replacement inherits role
records and governed artifacts, not hidden model memory or approval for new code.
